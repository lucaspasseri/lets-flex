# Phase 4 Media Catalog Coverage Plan

## Status and purpose

This is the Action 1 operational plan for Phase 4. It turns the read-only audit into a repeatable curation sequence. It does not authorize data change: each upload, assignment, or workflow refinement requires its separately approved action.

Optimize for effective recognition with minimal duplication. A direct base-exercise assignment is more valuable than a series of visually equivalent variant uploads. A coherent movement-pattern assignment is useful coverage, not a reason to skip a Tier 1 base exercise.

## Variant policy

The 129 global variants inherit by default. A direct override is justified only when the image must show a meaningful change in equipment, machine, body position, unilateral setup, or locomotion context. Following the Action 4 audit, Goblet Squat is the retained direct-override precedent: its kettlebell goblet position materially differs from the barbell back-squat base image. Barbell Bench Press, Bodyweight Push Up, One-Arm Dumbbell Row, Bilateral Leg Press, Bodyweight Glute Bridge, and Treadmill Running now inherit their directly assigned base assets because their former variant assignments either used the same asset or offered no meaningful visual distinction. The former Barbell Bench Press asset remains unassigned and reusable; it was not deleted. Dumbbell Bench Press remains the canonical base-inheritance example.

Action 4, not Action 2, decides additional direct overrides. Its record must name the visual difference and explain why base/pattern media is insufficient. It must reuse an existing reviewed asset whenever that is the deliberate choice.

## Curation workflow

1. Select the entity from this plan and check its current direct/effective state in Admin Media.
2. Confirm whether an existing approved asset, base assignment, or movement-pattern assignment is sufficient; reuse it when that is the deliberate visual choice.
3. Review subject/equipment accuracy, safe obvious form, 3:2-safe composition, palette/style fit, resolution, and absence of text, logo, watermark, corruption, or questionable anatomy.
4. Record creator/source, license or project origin, date, dimensions, reviewer, and direct/inheritance rationale in the provenance record.
5. Use the normal upload-and-assign or existing-asset assignment service. Supply English and Brazilian Portuguese alt text when the meaningful admin preview requires it.
6. Recheck the effective state. Do not overwrite a direct assignment without an explicit reviewed replacement decision.

Across human-subject assets, deliberately vary skin tones, ethnic backgrounds, gender presentation,
body builds, ages within adult training context, and other visible physical characteristics over the
collection. Preserve the same accurate, respectful exercise depiction and editorial visual family;
do not use stereotypes, exaggerated ethnic features, or tokenistic representation.

The current Admin Media entity-type filter, name search, effective-source preview, reuse, and safe assignment removal were sufficient for the completed curation batches. Action 5 found one bounded reuse bottleneck: the page loaded only its newest 50 assets, excluding intentionally preserved reusable asset 5 from the then-70-asset catalog. The page now requests the repository's existing 100-item maximum and labels each option with localized meaningful alt text when available, so the full current catalog is reachable and recognizable without a new mutation path. No coverage-state filter, batch operation, or broader navigation change is justified by the recorded Actions 2–4 evidence.

## Measurement and final reporting

Later actions update the baseline table using the same resolver-state definitions. Final reporting must distinguish direct assignments from inherited/contextual coverage, name intentional fallback gaps, list retained/deferred legacy findings, and state browser/manual verification limitations.
